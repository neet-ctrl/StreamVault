Build a fully native Android APK app called StreamVault using Kotlin + Jetpack Compose.

Goal:
Create a Stremio-like advanced streaming app that fetches movie streams from the Torrentio addon API using the open Stremio addon protocol, with a powerful built-in player like Stremio.

Important:
Use these open-source references as base architecture and code inspiration:

Stremio Core:
https://github.com/Stremio/stremio-core

Stremio Android TV:
https://github.com/Stremio/stremio-android-tv

Stremio Addon SDK:
https://github.com/Stremio/stremio-addon-sdk

Stremio Addon Protocol:
https://stremio.github.io/stremio-addon-sdk/

Torrentio API:
https://torrentio.strem.fun/manifest.json

Read and understand how Stremio:

- parses addon manifests
- resolves streams
- manages torrent sources
- handles subtitles
- handles playback state
- handles continue watching
- manages metadata

Build app architecture inspired by Stremio but fully optimized for Android phones.

Core system:

1. Search any movie/series
   Use TMDB API for:

- search
- trending
- popular
- upcoming
- top rated

2. On movie click:
   Get IMDb ID.

3. Query Torrentio:
   https://torrentio.strem.fun/stream/movie/{imdb_id}.json

4. Parse:

- title
- quality
- seeders
- file size
- provider
- language
- magnet URL

5. Show all sources like Stremio source cards.

Make a powerful built-in player by studying Stremio’s player implementation.
